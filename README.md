# BiGeo — Supplementary Material

Supplementary material for the anonymous submission **"BiGeo"** (under double-anonymous review).

## 📺 Project page — all videos playable here

### → **https://bigeo-research.github.io/** ←

The project page contains:

- the full **supplementary video** (3:02),
- individual **real-robot episodes** — MixTube, StackBaskets, PickAndPlace, ObjectSort,
- **simulation rollouts** on the 12 RoboTwin benchmark tasks.

## Repository contents

```
index.html                       The project page (served via GitHub Pages)
BiGeo_supplementary_video.mp4    Full supplementary video (32 MB, 3:02)
real_robot/                      Individual real-robot episodes per task (2x speed; StackBaskets 1.5x)
simulation/                      21 simulation rollout clips covering 12 RoboTwin tasks
assets/                          Poster images used by the project page
```

All sequences are executed **fully autonomously** by the learned policy; no teleoperation is used at test time. This repository contains no author- or institution-identifying information.
